# Калькулятор доставки за МКАД

Production-oriented веб-приложение для расчета доставки по Москве и Московской области: Next.js 16.3, TypeScript, PostgreSQL, Prisma 7, Yandex Maps API, Turf.js.

## Что реализовано

- пять типов транспорта из БД: Шаланда, Газель 3 м, Газель 6 м, Манипулятор, Манипулятор с катюшей;
- редактируемые базовая цена, ставка ₽/км за МКАД, минималка, грузоподъемность и коэффициент километража;
- Geosuggest + обязательное геокодирование выбранного адреса;
- реальный автомобильный/грузовой маршрут через Yandex Retrieving Route Details API;
- серверный расчет — клиент не присылает итоговую цену;
- полигон МКАД из 108 координатных точек по километрам кольца;
- геометрическое разбиение фактической полилинии маршрута на участки внутри/снаружи МКАД;
- несколько пересечений МКАД;
- несколько точек погрузки;
- округление километров NONE / NEAREST / CEIL;
- коэффициент километров ×1, ×2 или произвольный;
- проверка тоннажа;
- ручная корректировка с причиной;
- сохранение расчета и snapshot тарифа;
- номера вида `DLV-2026-000001`;
- история расчетов;
- карточка сохраненного расчета и «Создать PDF / печать» через print layout браузера;
- защищенная админ-панель с cookie JWT;
- миграция, seed, Docker Compose и unit-тесты.

## 1. API-ключи Яндекса

В кабинете разработчика Yandex Maps API подключите продукты, необходимые вашему тарифу/лицензии:

1. JavaScript API — интерактивная карта.
2. Geocoder — адрес → координаты.
3. Geosuggest — автодополнение адреса.
4. Retrieving Route Details / Router — серверное построение маршрута.

Создайте `.env` из `.env.example` и заполните:

```env
YANDEX_GEOCODER_API_KEY="..."
YANDEX_GEOSUGGEST_API_KEY="..."
YANDEX_ROUTER_API_KEY="..."
NEXT_PUBLIC_YANDEX_MAPS_API_KEY="..."
```

`NEXT_PUBLIC_YANDEX_MAPS_API_KEY` по природе JS API доступен браузеру; ограничьте ключ по домену в кабинете. Серверные ключи не имеют префикса `NEXT_PUBLIC_` и клиенту не отправляются.

## 2. PostgreSQL

Самый простой локальный запуск:

```bash
docker compose up -d postgres
```

В `.env`:

```env
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/delivery_calculator"
```

## 3. Установка

```bash
npm install
npm run db:generate
npm run db:deploy
npm run db:seed
npm run dev
```

Откройте `http://localhost:3000`.

## 4. Админка

Перед seed задайте:

```env
ADMIN_EMAIL="admin@example.ru"
ADMIN_PASSWORD="сильный-пароль"
AUTH_SECRET="случайная-строка-минимум-32-символа"
```

После `npm run db:seed` откройте `/admin`. Если сессии нет, приложение перенаправит на `/login`.

В админке заполните реальные тарифы. Seed намеренно создает транспорт с нулевыми тарифами — приложение не придумывает цены.

## 5. Как считается МКАД

`YANDEX_ROUTER_API_KEY` строит фактический автомобильный маршрут и возвращает полилинии каждого шага. Приложение объединяет их в GeoJSON LineString. `mkadService` затем пересекает этот LineString с Polygon МКАД и суммирует длины получившихся фрагментов.

Поэтому расстояние за МКАД — не прямая от объекта до кольца и не радиус от центра Москвы.

Встроенная граница находится в `src/data/mkad.geojson`. Это 108 контрольных координат по километрам МКАД. Для корпоративной эксплуатации можно заменить `AppSettings.mkadGeoJson` на собственный более детальный лицензированный GeoJSON без изменения алгоритма.

### Обе точки за МКАД

`AppSettings.outsideBothRule`:

- `FULL_OUTSIDE` — сумма всех частей реального маршрута за МКАД;
- `FARTHEST_FROM_MKAD` — самый длинный внешний фрагмент маршрута;
- `MANUAL` — расчет останавливается и требует решения менеджера.

## 6. Грузовые маршруты

Если для автомобиля заданы габариты/грузоподъемность, запрос Router отправляется с `mode=truck` и доступными параметрами машины. Доступность конкретных truck-параметров зависит от тарифа Yandex Maps API.

## 7. Старые расчеты

В `Calculation` сохраняются:

- basePriceKopeksSnapshot;
- outsideRateKopeksSnapshot;
- distanceMultiplierSnapshot;
- tariffSnapshot;
- routeGeoJson;
- рассчитанный километраж и итог.

Поэтому изменение тарифа в админке не меняет сохраненные расчеты.

## 8. PDF

На странице сохраненного расчета кнопка **«Создать PDF / печать»** вызывает print-layout. В Chrome/Edge выберите «Сохранить как PDF». Такой подход корректно печатает кириллицу без хранения серверных файлов шрифтов.

## 9. Тесты

```bash
npm test
```

Есть тесты округления/коэффициентов и базовой геометрии МКАД. Интеграционные тесты Yandex API требуют действующих API-ключей и интернет-доступа.

## 10. Production

1. Поднимите PostgreSQL.
2. Задайте environment variables в хостинге.
3. Выполните `npm ci`.
4. Выполните `npm run db:deploy` и один раз `npm run db:seed`.
5. Выполните `npm run build`.
6. Запустите `npm start`.
7. Ограничьте Yandex JS API key production-доменом, а серверные ключи — допустимыми ограничениями кабинета.
8. Используйте HTTPS и сильный `AUTH_SECRET`.

## Ограничение запуска в переданном архиве

В архиве нет ваших коммерческих API-ключей и подключения к вашей PostgreSQL, поэтому реальные запросы к Yandex API начинают работать сразу после заполнения `.env` и применения миграций. Никаких mock/fake-route в production-коде нет.
